# Sr. Rotas 2.0 — Alpha 0.6.0

Sr. Rotas é um copiloto Android para motoristas de aplicativo. O núcleo usa MediaProjection autorizada pelo usuário, OCR local, parser contextual e HUD nativo de rentabilidade.

**Desenvolvido pela BigCorps** — contato@bigcorps.com.br

## 0.6 — Design System e UX

A fase 0.6 transforma o Alpha técnico em uma base de produto utilizável:
- navegação Início / Jornada / Histórico / IA / Perfil;
- Design System próprio;
- novo HUD “Painel de Rota”;
- Compacto / Normal / Grande;
- toque para fechar;
- segurar e arrastar para reposicionar;
- posição persistente;
- tema e fonte configuráveis.

## Offer Engine

O motor está congelado na lógica validada da 0.5.4. A versão do aplicativo sobe para `0.6.0-alpha`, mas ofertas continuam registrando `parser_version = sr-rotas-v0.5.4` para manter rastreabilidade.
