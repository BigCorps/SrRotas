# Origem dos ativos visuais desta etapa

Os VectorDrawables `sr23_float_*` foram derivados diretamente do kit fornecido pelo usuário nesta conversa: `Kit_Design_Janela_Flutuante_Sr_Rotas_v1.0.zip`.

Os nomes foram prefixados para evitar colisão com recursos já existentes no aplicativo. A aplicação usa tint em runtime para suportar os temas Light e Dark sem rasterização.
