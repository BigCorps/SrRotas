# Fase 0.6 — Checklist de aceite

A fase é considerada aprovada quando:

- [ ] Navegação funciona em tela pequena sem overflow horizontal.
- [ ] Botões principais têm área de toque confortável.
- [ ] Início de jornada continua exigindo consentimento e permissão de overlay.
- [ ] HUD Compacto é legível sem ocupar área excessiva.
- [ ] HUD Normal é o melhor equilíbrio para uso diário.
- [ ] HUD Grande mostra informações extras sem cortar a tela.
- [ ] Toque fecha apenas o HUD atual; a próxima oferta volta a aparecer normalmente.
- [ ] Long press + arrastar move o HUD sem executar toque no Uber por baixo do card.
- [ ] Nova posição persiste nas ofertas seguintes.
- [ ] Reset de posição funciona.
- [ ] Tema claro/escuro funciona.
- [ ] Fonte funciona independentemente do tamanho do card.
- [ ] Ordem/seleção das métricas funciona.
- [ ] Parser e Card Stabilizer continuam com o comportamento da 0.5.4.
- [ ] GitHub Actions passa em testes/build/upload.

Se estes itens passarem, a próxima entrega será a **fase 0.7 completa** (conta, onboarding e app autossuficiente), em um único ZIP incremental.
