# Teste Uber — Sr. Rotas 2.0 Alpha

Este arquivo substitui o roteiro do primeiro MVP.

Use o roteiro atualizado em `docs/TESTE-UBER-SRROTAS.md`.

Resumo:

1. permita o HUD (`Exibir sobre outros apps`);
2. toque em **Iniciar jornada**;
3. autorize o compartilhamento de tela do Android;
4. abra o Uber Driver;
5. aguarde uma oferta;
6. confira valor, R$/km, R$/hora e lucro estimado no HUD;
7. se algo vier errado, copie o diagnóstico local.

MediaProjection é o motor principal; Acessibilidade é auxiliar.
